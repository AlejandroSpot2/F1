Method

Methodology

The analysis uses FastF1 race-session data, then summarizes each race into a small set of presentation-friendly measures. D3.js renders the charts directly in the page so every view can be inspected with tooltips, while GSAP ScrollTrigger coordinates the cinematic scroll moments between chapters.

Data

FastF1 provided lap timing, position, speed-trap, and session status data for Australia, China, Japan, Miami, and Canada across 2025 and 2026.

Metrics

Green-flag lap pace, fastest lap, clean-lap speed trap, neutralized laps, DNFs, and a position-change proxy were derived for comparison.

Visualization

D3.js powers the bars, step charts, slope graph, timeline heatmap, scorecard, legends, and interactive tooltips.

Story Layer

GSAP ScrollTrigger and Lenis drive pinned arcade transitions, chapter color shifts, and scroll-scrubbed motion across the story.
